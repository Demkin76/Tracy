# Tracy 1.1 — каталог и запуск личных агентов

Основной маршрут теперь: Explore agents → Use agent → собственные настройки и лимиты →
Install agent → Installed agents → Run once / Start schedule → Inspect proof.

Доступны выплаты по списку и ограниченные по числу циклов выплаты по расписанию.
Каждая установка имеет отдельный ключ, приватную историю и свои правила.
Задания сохраняются на сервере и выполняются после закрытия браузера.
История исходного агента остаётся на его профиле; автор не может менять настройки чужой копии.

Практическая инструкция и объяснение всех разделов: [MARKETPLACE.md](MARKETPLACE.md).
План минутной демонстрации: [DEMO-1MIN.md](DEMO-1MIN.md).

Выполняются поддерживаемые программы Tracy, а не произвольный код внешнего автора.
Используется общий спонсорский кошелёк с тестовым SOL и отдельными квотами.
Публичное размещение в интернете, Mainnet и продажа услуг за реальные деньги в этот релиз не входят.

# Tracy 1.0 — готовая платформа на Devnet

Объём согласован: каталог агентов и проверяемых действий, без покупки услуг за реальные деньги.

## Открыть

- Каталог: http://127.0.0.1:8000/explore
- Кабинет: http://127.0.0.1:8000
- Методология: http://127.0.0.1:8000/methodology
- API: http://127.0.0.1:8000/docs

Локальный владелец: owner@tracy.local. Пароль хранится в data/tracy-owner.json. Не публикуйте этот файл.

## Полный пользовательский путь

1. Создать аккаунт, подключить собственного бота через SDK либо создать браузерного агента.
2. Установить получателей, разовый и суточный лимиты. Владелец может остановить агента.
3. Отправить подписанное намерение. Tracy проверит подпись, политику, бюджет агента, квоту аккаунта и общую квоту платформы.
4. Получить настоящую Devnet-транзакцию или подписанный отказ. Незавершённые операции автоматически перепроверяются без повторной отправки.
5. Изучить историю с фильтрами, CSV, аналитику и уведомления.
6. Явно опубликовать профиль со всей историей либо создать временную ссылку на отдельную квитанцию.
7. Гость без аккаунта может найти агента, сравнить показатели, открыть доказательство и проверить его. Владелец может отозвать публикацию и ссылки.

## Возможности

| Раздел | Реализовано |
|---|---|
| Каталог | Поиск, категории, сортировка, страницы результатов |
| Профиль | Описание, ключ, полная опубликованная история и метрики |
| Сравнение | До трёх агентов, размер выборки и единые показатели |
| Рейтинг | Прозрачная формула; нет оценки при недостаточной истории |
| Избранное | Личный список публичных агентов |
| Доказательства | Подписи, хеши, цепочка, свежий RPC, JSON |
| Приватность | Закрыто по умолчанию, явная публикация, срок и отзыв ссылки |
| История | Все агенты, статус, даты UTC, поиск, пагинация, CSV |
| Аналитика | 7/30/90 дней, объём, исходы, дневная активность |
| Исполнение | Атомарные бюджеты, Stop, версии политик, защита от повторов |
| Надёжность | Фоновая проверка, задержки повторов, восстановление после рестарта |
| Доступ | Сессии, CSRF, смена пароля, одноразовый код восстановления |
| API-ключи | Управление или только чтение, срок, отзыв, журнал событий |
| SDK | CLI, отдельный бот, постоянные ID заданий, публичные методы |
| Эксплуатация | Запуск PowerShell, резервные копии, Docker/Compose, CI |

## Запуск и эксплуатация

Команда из корня: ./Start-Tracy.ps1 -SkipBuild. Для сборки зависимостей и интерфейса уберите -SkipBuild. Используется один worker; блокировка защищает БД от второго процесса.

Полная инструкция, SDK, резервирование и развёртывание: [README.md](README.md).

Релиз работает локально. Для внешней ссылки ещё нужны выбранный сервер, домен и HTTPS. Используется общий спонсорский Devnet-кошелёк с лимитами; это не Mainnet и не хранение реальных средств. Email не подтверждается письмом: восстановление выполняется по заранее сохранённому коду.
