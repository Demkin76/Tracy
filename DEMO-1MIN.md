# Tracy: минутная демонстрация выбора и запуска агента

Откройте http://127.0.0.1:8000/explore и заранее войдите в кабинет владельца.
Логин owner@tracy.local, пароль в data/tracy-owner.json.
Готовые личные экземпляры и проверенная квитанция перечислены в data/marketplace-owner-demo.json.
Не показывайте файл пароля на демонстрации.

| Время | Показать | Сказать |
|---|---|---|
| 0–10 с | Каталог, профиль Atlas | «Здесь выбираем агента и смотрим подтверждённую историю его действий». |
| 10–25 с | Use agent: получатели, суммы, лимиты | «Подключаем отдельную копию себе и задаём собственные ограничения». |
| 25–40 с | Installed agents: готовая копия Atlas, Run once | «Tracy выполняет задачу на Devnet и сохраняет проверяемый результат». |
| 40–50 с | Inspect proof готового успешного запуска, затем отказ | «Перевод проверен в блокчейне. Выход за мой бюджет отклонён до отправки». |
| 50–60 с | Sentinel: два завершённых цикла, Stop | «Агент работает по расписанию без открытого браузера. Количество запусков и расходы ограничены владельцем». |

Для первой демонстрации используйте уже готовую историю, если RPC отвечает медленно.
Новый Run once действительно повторяет текущий список выплат.
У подготовленного Atlas после тестирования дневной лимит увеличен до 0.003 SOL;
в истории сохранён отказ, полученный при прежнем лимите 0.0000015 SOL.
Квитанция содержит версию правил, действовавшую в момент конкретного действия.

Краткое обновление статуса:
«Добавлен полный путь: выбрать агента, подключить личную копию, задать лимиты,
запустить и проверить результат. Работают выплаты по списку и расписанию.
Проверены изоляция пользователей, запрет повторных платежей, Stop и реальные Devnet-переводы».

Границы показа: программы выплат размещены на сервере Tracy; произвольный код автора не загружается.
Средства тестовые, кошелёк платформы общий. Сайт пока работает локально.
